# Apprentice Guided Practice

Apprentice users need structure before autonomy.

## What This Role Can See

- Public and member documentation.
- Apprentice-specific guided practice material.
- Operation cards for practice work they are authorized to run.
- Help that explains evidence, review, and safe execution.

## What This Role Can Do

- Naming the job to be done.
- Providing useful evidence.
- Reviewing an operation card.
- Completing a small work loop.
- Asking for help from the handbook when blocked.

## What This Role Cannot Do

- View staff operations, admin appliance controls, backup/restore controls, or provider/tool governance.
- Skip evidence review for destructive or externally visible work.
- Escalate practice tasks into staff production work without staff/admin involvement.

## When To Expose An Operation Card

Expose `onboarding_flow`, `help_flow`, or low-risk practice operation cards when the apprentice is learning a workflow. The card should show one safe next action at a time and make completion evidence visible.

## When To Ask A Clarifying Question

Ask a clarifying question when the apprentice has not named the outcome, the source evidence, the audience, or the review standard. Keep the question concrete and connected to the next operation step.

## Evidence To Inspect

Inspect the apprentice-visible operation card, action state, event trail, artifacts, and relevant handbook chapter before giving guidance. Teach the user to compare the assistant summary against operation evidence.

The assistant should explain why a step matters without exposing staff-only production controls.

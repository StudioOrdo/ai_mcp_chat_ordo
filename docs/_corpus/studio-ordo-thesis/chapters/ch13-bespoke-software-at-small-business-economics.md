# 13. Bespoke Software at Small-Business Economics

Traditional SaaS scales by making customers more similar.

Ordo scales by keeping the foundation common while allowing workflows to become specific.

The platform provides the shared substrate:

* identity
* website
* CRM
* publishing
* media production
* search
* job orchestration
* AI interface
* relationship memory
* referral attribution
* MCP capability catalog

But the lived product can become different for each customer.

A yoga studio can get class packs, wellness content, referral cards, student follow-up, and membership workflows.

A teacher can get lecture ingestion, study guide generation, quiz creation, and subscription learning libraries.

A consultant can get client intake, report generation, knowledge-base publishing, and paid briefing workflows.

A photographer can get portfolio generation, inquiry routing, package recommendations, and referral attribution.

These are not separate SaaS companies.

They are capabilities.

They are tools.

They are workflows.

They are prompt packs.

They are MCP extensions.

The unit of customization becomes smaller than a whole product.

That is what makes small markets worth serving.

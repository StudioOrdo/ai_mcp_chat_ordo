# Feature Specs

Status: Planned

These specs define the product features needed to reach the Ordo target shape.
Each spec records:

- feature goal,
- current code to reuse or modify,
- implementation needs,
- cleanup after replacement,
- positive, negative, and edge tests grounded in current test patterns.

The specs are intentionally product-level. Implementation phases should refresh
code grounding before editing because this worktree is moving quickly.

# Stage 08 - Scrollytelling Recipe MVP

## Goal

Ship the first constrained scrollytelling workflow.

## Build

- Define scrollytelling brief.
- Define research plan stage.
- Define research packet artifact.
- Define outline and section draft artifacts.
- Define media plan.
- Support a constrained page composition with fixed section patterns.
- Add QA gates for factual support, citations, accessibility, mobile layout,
  and media rendering.

## Done

- A user can start from a topic and produce a reviewable scrollytelling draft.
- Every source, claim, media item, and QA finding has durable lineage.

## Guardrails

- Do not build a general page builder.
- Do not let media assets become detached from the page composition.

# Stage 06 - QA Gate System

## Goal

Make QA a first-class workflow system.

## Build

- Define QA gate types.
- Define QA report schema.
- Define pass, warn, fail, blocked, and needs-human-review states.
- Define revision triggers.
- Define human Tier 4 review handoff.
- Connect QA reports to artifacts, evidence, and stage runs.

## Done

- Scrollytelling and Ordo development can share QA concepts.
- QA reports can block release.
- Failed QA can produce a revision work order or pause for human review.

## Guardrails

- Do not let tests replace functional review.
- Do not let the model self-certify release quality without evidence.

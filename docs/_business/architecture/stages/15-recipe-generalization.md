# Stage 15 - Recipe Generalization

## Goal

Generalize recipes only after the first two flagship workflows prove the model.

## Build

- Extract shared recipe metadata from scrollytelling and Ordo development.
- Define recipe versioning.
- Define recipe installation and migration.
- Define recipe-specific prompt customization limits.
- Define recipe-specific projection registration.
- Define tests for adding a new recipe without core edits.

## Done

- A new solopreneur workflow can be added as a recipe instead of a new platform
  subsystem.
- The core remains small.

## Guardrails

- Do not build a generic recipe marketplace before internal recipes are stable.
- Do not let recipes redefine kernel contracts.

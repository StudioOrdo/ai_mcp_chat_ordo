# Stage Roadmap

This roadmap is split into reviewable stages.

Unlike the original greenfield sequence, this version starts from the current
implemented baseline and focuses on convergence.

## Stage Sequence

0. Reality sync: docs reflect implemented runtime and product thesis
1. Conversation spine hardening: prompt continuity, memory projection,
   cross-surface consistency
2. Job and work-order reconciliation: durable state to presentation alignment
3. Artifact lineage consolidation: unify compatibility across blog, factory,
   media, and materialization surfaces
4. Recipe contract introduction: add recipe mapping over existing work orders
5. Business process projections: referral, lead, consult, deal, delivery, and
   next-action views
6. Hosting and tenancy baseline: isolation model, storage and processing meter
   hooks, exportability contract
7. WASM execution contract: governed browser execution for bounded workloads and
   script runtime envelope
8. Agent federation foundations: signed identity, policy envelope, audit
   receipts
9. Release and evidence hardening: reproducible proof artifacts for product and
   business claims

## Completion Standard

Each stage should finish with:

- docs updated
- affected current code mapped
- positive, negative, and edge cases listed
- implementation completed or explicitly deferred
- tests or manual verification listed
- next-stage assumptions updated

## Stop Rule

If a stage discovers vocabulary drift from runtime reality, stop and update the
docs and contracts before further implementation.

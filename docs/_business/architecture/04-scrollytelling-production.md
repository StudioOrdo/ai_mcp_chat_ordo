# Scrollytelling Production

## Purpose

Scrollytelling production is the first flagship content workflow.

It proves that Ordo can turn trapped expertise and external research into a
durable multimedia artifact.

## MVP Shape

Constrain the first version:

- 5 to 8 sections
- mobile-first page
- citation drawer or source notes
- media slots per section
- support for text, chart, graph, image, and audio
- one publish target
- bounded QA and revision loop

Avoid building a general page builder first.

## Workflow

```text
brief
-> research plan
-> local/web/connector research
-> research packet
-> story outline
-> section drafts
-> media plan
-> charts, graphs, audio, images
-> composed scrollytelling page
-> QA
-> publish
-> derivatives
-> observe and revise
```

## QA Gates

Required gates:

- factual support
- citation coverage
- source policy compliance
- mobile layout
- accessibility
- media rendering
- performance budget
- editorial quality
- publish readiness

## Current Code To Reuse

- factory work orders and stage runs
- blog/journal editorial artifacts
- media generation and composition
- materialization and asset catalog
- capability catalog
- job timeline projection

## Do Not Build Yet

- freeform visual page builder
- arbitrary animation editor
- custom CMS node hierarchy
- prompt-only content workflow
- multi-tenant marketplace templates

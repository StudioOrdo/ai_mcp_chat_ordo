## The Operating Shape

The operator stays in one continuous conversation.

When work is requested, the assistant routes it through the capability catalog.
If execution is heavy, it is delegated to factory/deferred paths and returned to
the same thread with status and artifacts.

## Production Loop

The primary loop is:

1. intent or brief
2. context and evidence
3. planning and execution
4. artifact delivery and QA
5. revision and release
6. follow-up and learning

## Capability Catalog As Compiler

The catalog is the execution surface.

- human expresses intent in language
- system maps intent to governed capabilities
- runtime routes by target (host, deferred, browser, MCP, remote)

## Durable Value

The engine is not just asset generation. It is operational continuity:

- memory of goals and commitments
- visible execution state
- reusable artifacts
- governed quality gates

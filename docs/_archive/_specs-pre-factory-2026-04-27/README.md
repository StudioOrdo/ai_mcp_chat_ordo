## Rules

1. Put user-facing feature specs here, not under `_refactor/`.
2. Use one folder per feature.
3. Keep the feature folder limited to the current product contract, implementation phases, and evidence artifacts.
4. Move superseded drafts into `_archive/` rather than leaving parallel versions active.
5. New active feature packages should follow the three-rail structure in `docs/operations/ai-phase-delivery-process.md`.

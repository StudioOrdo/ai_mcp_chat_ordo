# Spec Archive

This folder holds inactive, superseded, or parked spec packages that should remain available for historical reference without competing with the active delivery queue.

Archive rules:

1. Do not treat archived packages as active commitments.
2. If a package becomes active again, either restore it as the single active package or extract only the still-valid material into a new active package.
3. Leave evidence and prior phase history intact unless there is a specific reason to prune it.
